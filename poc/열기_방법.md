# PoC 뷰어 여는 법

## ★ 제일 쉬운 방법 — Vercel (설치 0, 링크로 열기)

레포 루트 `vercel.json` 이 `poc` 폴더를 정적 사이트로 배포하도록 설정돼 있다.

1. https://vercel.com → **Continue with GitHub** (레포 있는 GitHub 계정으로 로그인)
2. 대시보드 → **Add New… → Project**
3. **Import Git Repository** 에서 **Mir_Update_V2** 찾기 → **Import**
   - 목록에 없으면 "Adjust GitHub App Permissions" 로 이 레포 접근 허용
4. 설정 화면은 **그대로 두고**(vercel.json 이 알아서 함) → **Deploy**
5. ~1분 뒤 완료 → **Visit** 클릭 → `https://mir-update-v2-xxxx.vercel.app` 주소가 생김
6. 그 주소 열기 → 3D 지형 표시 (15MB 모델이라 처음 몇 초 로딩)

> 이후 브랜치에 커밋이 푸시되면 Vercel 이 자동 재배포한다.
> xeokit AGPL — 자체 확인용 임시 배포. 테스트 후 내리거나 비공개 권장(외부 상시공개는 법무 확인).

## 0. 레포 최신본 받기
이미 PC에 레포가 있으면:
```
git pull origin claude/mir-smart-3d-viewer-djxloi
```
없으면 (한 번만):
```
git clone https://github.com/Kojongchan/Mir_Update_V2.git
```

> 압축 풀어도 됩니다. (단, `claude/mir-smart-3d-viewer-djxloi` 브랜치를 선택하고 받으세요.)

## 1. 서버 켜기 (`poc` 폴더 안에서)

로컬 파일을 브라우저가 3D로 읽으려면 "웹서버"로 띄워야 합니다(그냥 더블클릭은 안 됨).
아래 중 **하나**만 하면 됩니다.

### 방법 A — Python (대부분 PC에 이미 있음, 제일 간단)
```
cd poc
python -m http.server 8099
```
(맥/리눅스에서 안 되면 `python3 -m http.server 8099`)

### 방법 B — Node.js 있으면
```
cd poc
npx http-server -p 8099 -c-1
```

둘 중 뭘 쓰든, 터미널에 "서버가 8099에서 돈다"는 메시지가 나오면 **그 창은 켜둔 채로** 둡니다.

## 2. 브라우저로 열기
크롬 등에서:
```
http://localhost:8099/index.html
```
(`localhost` = `127.0.0.1`, 같은 뜻입니다. 이제 당신 PC에서 서버가 도니까 열립니다.)

## 3. 확인할 것 (R1 최종 판정)
지형이 뜨면, 화면 아래 버튼으로 카메라를 움직이며 눈으로 확인:
- **자동 회전 on/off** → 빙글빙글 돌 때 화면 오른쪽 위 **FPS 숫자가 55~60 이상** 유지되는가
- **근접(지터 최악 조건)** → 바짝 붙었을 때 지형이 **떨리거나(지터) 면이 깜빡(z-fighting)** 안 하는가

두 개 다 괜찮으면 **R1 통과** → 다음 단계(구조물 정합)로 갑니다.
이상하면(느리거나 떨리면) 그 화면 스크린샷 찍어서 알려주세요.

## 문제 해결
- **"python 명령을 찾을 수 없음"** → https://www.python.org 에서 설치, 또는 방법 B(Node) 사용.
- **화면이 까맣고 아무것도 없음** → 주소가 `.../index.html` 맞는지, `poc` 폴더 안에서 서버를 켰는지 확인.
- **`out/ground.glb` 없음 에러** → `git pull` 로 최신본을 받았는지 확인(이 파일이 이제 레포에 포함됨).
